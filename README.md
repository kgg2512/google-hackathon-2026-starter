# Ariadne — event-day preservation record

Ariadne aims to keep differences in AI literacy from becoming differences in personal digital safety. It helps people decompose suspicious relationships, claims, evidence and requested actions, then find independent confirmation and support. Its name draws from Ariadne's thread through the labyrinth.

**The submission was not completed by 15:20 KST on 16 October 2026.** A prototype and public source existed; full functional validation, an accessible playable demo video and a submission receipt were not established. This repository is a development record, not a claim of production readiness or successful submission.
